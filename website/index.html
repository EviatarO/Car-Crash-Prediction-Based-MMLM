Research goal

Teaching a vision model to see why, not just whether

The problem

A collision label carries one bit. A model trained on that alone must infer the whole causal structure of a near-miss — closing distance, brake lights, an occluded turn — from a single yes/no signal per clip.

The hypothesis

During training only, a vision-language teacher describes each clip in words. The student reproduces the meaning of that description alongside the crash label — supervision far richer than the label itself — shaping a visual representation that encodes why a scene is dangerous, not only that it is.

At inference: vision only

The teacher, the captions, and the whole language branch are dropped once training ends. What ships is the vision encoder alone — same architecture, same cost, same latency as the crash-only model, with no text input and no captions required at run time.

Architecture

One trunk, two objectives

The crash path is unchanged from a vision-only model. A second branch, used only at training time, aligns pooled visual features with the teacher's caption — then is discarded entirely.
